# Ветеринарная Клиника "Айболит"

Веб-приложение для автоматизации работы ветеринарной клиники. Проект реализует полный цикл взаимодействия: от просмотра базы специалистов до ведения детализированной истории болезней питомцев.

Приложение спроектировано с упором на мобильные устройства. Для лучшего пользовательского опыта рекомендуется открывать сайт со смартфона или использовать режим эмуляции мобильного устройства в браузере.

## Технологический стек

* **Frontend:** JavaScript, React.js, React Router v6, Vite.
* **Backend / База данных:** Supabase (PostgreSQL).
* **Стилизация:** Pure CSS (подход CSS Modules, Flexbox/Grid).

## Реализованный функционал

### 1. Запись к врачу (Appointment)
* **Умный расчет слотов:** Приложение автоматически рассчитывает свободное время выбранного врача, исключая уже занятые слоты и прошедшее время текущего дня.
* **Валидация:** Блокировка записи на прошедшие даты и обязательный выбор специалиста.
* **База врачей:** Динамическая подгрузка списка доступных специалистов из базы данных.

### 2. Новый пациент (New Patient)
* Регистрация владельца по номеру телефона с автоматическим форматированием ввода.
* Добавление питомца с указанием вида, породы, возраста, веса и индивидуальных особенностей (хронические заболевания, травмы).

### 3. Медицинские карточки (Medical Cards)
* **История болезней:** Просмотр всех прошлых визитов (реализовано через раскрывающийся список).
* **Редактирование данных:** Возможность обновлять информацию о питомце в реальном времени.
* **Удаление:** Безопасное удаление медицинской карты вместе со всей историей посещений.

### 4. Режим Врача (Doctor Mode)
Для демонстрации профессионального функционала реализован специальный тумблер переключения режимов.
Как использовать:
1. Перейдите в раздел "Мед. карты".
2. Найдите клиента по номеру телефона (или создайте нового).
3. Активируйте чекбокс "Режим врача" над списком пациентов.
4. В этом режиме открывается дополнительный функционал:
   * Кнопка редактирования профиля питомца.
   * Поля для ввода диагноза и медицинского заключения в истории посещений.

## Структура Базы Данных

В качестве Backend-решения используется реляционная база данных PostgreSQL, развернутая на платформе Supabase. Файл инициализации структуры базы данных (`database-schema.sql`) доступен в корне проекта.

**Основные таблицы и связи:**
* **owners (Владельцы):** Хранит контактные данные клиентов. Один владелец может иметь несколько питомцев (связь One-to-Many).
* **pets (Питомцы):** Хранит медицинские карты животных. Привязана к таблице владельцев.
* **doctors (Врачи):** Хранит информацию о специалистах, их график работы и биографию.
* **appointments (Записи на прием):** Связывает питомца и врача (Many-to-One). Содержит дату, время, причину обращения и диагноз.

Настроены внешние ключи (Foreign Keys) и каскадное удаление. При удалении питомца автоматически очищается вся его медицинская история.

## Инструкция по запуску

Проект использует Supabase. Ключи доступа к тестовой базе данных сохранены в файле `src/supabaseClient.js` для удобства проверки.

1. Клонируйте репозиторий на свой локальный компьютер:
   ```bash
   git clone <URL_вашего_репозитория>
   ```
2. Перейдите в директорию frontend:

  ```bash
  cd frontend
  ```
3. Установите необходимые зависимости:

  ```bash
  npm install
  ```
4.Запустите сервер для разработки:

  ```bash
  npm run dev
  ```
Откройте предоставленную локальную ссылку (обычно http://localhost:5173) в вашем браузере.
