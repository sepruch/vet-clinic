# Ветеринарная Клиника "Айболит"

Веб-приложение для работы ветеринарной клиники. Разработано в рамках тестового проекта.
Проект реализует полный цикл взаимодействия: от просмотра специалистов до ведения истории болезней питомцев.

> **Мобильный дизайн**
>
> Приложение спроектировано и оптимизировано специально для **мобильных устройств**.
> Для лучшего пользовательского опыта (UX) и корректного отображения верстки рекомендуется:
> * Открывать сайт со смартфона.
> * Или использовать режим эмуляции мобильного устройства в браузере (**F12** -> **Toggle Device Toolbar**).

## Технологический стек (Requirements)

* **Frontend:** JavaScript, React.js (Hooks, Functional Components), React Router v6.
* **Backend / Database:** Supabase (PostgreSQL).
* **Styling:** Pure CSS (CSS Modules approach, Flexbox/Grid).

## Реализованный функционал

### 1. Запись к врачу (Appointment)
* **Умный расчет слотов:** Приложение автоматически рассчитывает свободное время врача, исключая уже занятые слоты и прошедшее время.
* **Валидация:** Нельзя записаться на прошлое или не выбрать врача.
* **База врачей:** Динамическая подгрузка списка специалистов из БД.

### 2. Новый пациент (New Patient)
* Регистрация владельца по номеру телефона.
* Добавление питомца с указанием вида, породы, возраста и особенностей.
* Валидация формата телефона.

### 3. Медицинские карточки (Medical Cards)
* **История болезней:** Просмотр всех прошлых визитов (реализовано через UI-компонент "аккордеон").
* **Редактирование (CRUD):** Возможность обновлять данные питомца (вес, возраст, хронические болезни).
* **Удаление:** Возможность удалить карточку вместе с историей.

## "Режим Врача" (Doctor Mode)

Для демонстрации функционала заполнения диагнозов реализован **Demo-тумблер**.

1. Перейдите в раздел **"Мед. карты"**.
2. Введите номер телефона клиента (или создайте нового).
3. Нажмите галочку **"Режим врача"** над списком.
4. **Возможности в этом режиме:**
   * Появляется кнопка **"✏️"** для редактирования данных питомца.
   * В истории посещений открываются поля для ввода **Диагноза** и **Заключения**.

## Структура Базы Данных (Database Schema)

В качестве Backend-решения выбрана реляционная база данных **PostgreSQL** (Supabase).

**Схема данных:**
![Database Schema](./schema.svg)

*Также доступен [полный SQL дамп структуры базы данных](./database-schema.sql) для развертывания.*

### Описание связей:
* **One-to-Many:** Один `Owner` может иметь много `Pets`.
* **Many-to-One:** Много `Appointments` относятся к одному `Pet` и одному `Doctor`.
* Настроены `Foreign Keys` и каскадное удаление (`ON DELETE CASCADE`), чтобы при удалении питомца очищалась и его история.

## Запуск проекта

Для удобства проверки, ключи доступа к тестовой базе данных Supabase (`anon_key`) **оставлены в исходном коде** (`src/supabaseClient.js`). 

1. **Клонируйте репозиторий:**
   ```bash
   git clone <https://github.com/sepruch/vet-clinic>
   npm install
   npm start
   ```
   Приложение будет доступно по адресу http://localhost:3000 (или 5173 для Vite).
